ImageUpload Component Test

This page tests the ImageUpload component by programmatically injecting a file into the create-campaign form.

Waiting for create-campaign page to load...

Navigate to Create Campaign first, then come back here.

How to test:

  1. Open the browser console on the create-campaign page
  2. Paste and run the script below

Test Script (paste in console on /create-campaign):

fetch('/test-campaign-image.png')
  .then(r => r.blob())
  .then(blob => {
    const file = new File([blob], 'test-campaign-image.png', { type: 'image/png' });
    const input = document.getElementById('campaign-cover-image');
    const nativeInputValueSetter = Object.getOwnPropertyDescriptor(
      window.HTMLInputElement.prototype, 'value'
    ).set;
    const dt = new DataTransfer();
    dt.items.add(file);
    input.files = dt.files;
    // React 19 uses native events
    const event = new Event('change', { bubbles: true });
    input.dispatchEvent(event);
    console.log('File injected, onChange should trigger upload');
  });
